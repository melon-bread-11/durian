# Two-week learning roadmap

The scaffold is a foundation. Practise explaining each request from browser to database.

| Days  | Practice                                                                                                       |
| ----- | -------------------------------------------------------------------------------------------------------------- |
| 1–2   | Read the structure, run locally, customise farm content, deploy a preview                                      |
| 3–4   | Replace sample varieties and illustrations with confirmed information and farm photos; practise mobile styling |
| 5–6   | Connect PostgreSQL, inspect the schema and migration, seed examples, and query data                            |
| 7–8   | Trace the enquiry form through the API and database; extend validation and tests                               |
| 9–10  | Add authentication, then protected admin catalogue editing and enquiry views                                   |
| 11–12 | Test authorisation, error states, keyboard navigation, and mobile layout                                       |
| 13–14 | Configure production settings, migrations, anti-spam protection, verify deployment, and rehearse a demo        |

For each feature: make a branch, build a small change, verify it, review the diff, commit, and open a pull request. Payments and a shopping cart can wait until a later release.
